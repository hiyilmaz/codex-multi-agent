# Status Messages

**Status:** Active

Default Turkish messages for common stop or wait states.

| State | Message |
|---|---|
| error | Hata oluştu, seni bekliyorum. |
| permission_required | Devam etmek için izin vermelisin. |
| completed | Görev tamamlandı, yeni talimatını bekliyorum. |
| decision_required | Karar gerekiyor, seni bekliyorum. |
| blocked | İlerleyemiyorum, kararını bekliyorum. |

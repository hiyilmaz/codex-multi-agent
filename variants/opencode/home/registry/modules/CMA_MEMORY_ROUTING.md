# CMA Memory Routing Module

## Load When

Load when prior decisions, workspace conventions, earlier evidence, or memory
citations are material to the current task.

## Do Not Load When

Do not load for self-contained stable questions, translations, or trivial
formatting.

## Rules

- Search the memory registry with two to four narrow keywords.
- Open only directly matched entries and at most the necessary rollout files.
- Use memory for historical context, not as current external-state proof.
- Revalidate drift-prone paths, versions, hosts, runtime state, and test output.
- State when an unverified historical fact may be stale.
- Follow the active environment's exact memory citation format when memory
  files are used.

# Hypothesis Workflow

Before the solution attempt, append Problem, Evidence, Hypothesis, Solution
Attempt, Test, Success Criteria, Result, Decision, and rollback boundaries to
the existing project experiment log. Use NEED_MORE_DATA until evidence supports
ACCEPT or REJECT. Never create a second changelog.

# CMA Documentation Research Module

## Load When

Load for current APIs, models, framework behavior, releases, standards, laws,
or claims that need primary-source verification.

## Do Not Load When

Do not load for stable facts already established by local source or supplied
content.

## Rules

- Prefer official documentation, specifications, source repositories, and
  first-party release notes.
- For technical questions, rely on primary sources.
- Treat Reddit, forums, and community reports as practical experience only.
- State conflicts and give more weight to authoritative current evidence.
- Cite claims near the supporting source and avoid excessive quotation.
- For Anthropic and Claude Code products, use the active primary-documentation
  workflow and official Anthropic sources.
